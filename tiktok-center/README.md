# TikTok Astrology Center

`tiktok-astrology-center.html` is the full TikTok Astrology Center for
adventuresinastrology.com/tiktok-astrology. It holds the menu, the tabs and the
built-in LIVE Classroom with its lessons, Explore slideshows and follow-along calculator.

The Squarespace page only holds a small loader code block (`loader.html`).
The loader fetches this file, so **editing this file updates the live page**
(allow a few minutes for caching).
